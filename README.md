# Keanu Reeves Outreach

Static migration of the Keanu Reeves Outreach website. The repository contains all pages, styling, imagery, responsive navigation, and client-side form feedback required to run on any static host.

## Run locally

Open `index.html` directly, or serve this directory with any static web server.

## Pages

- Home
- About Us
- Programs
- Campaigns
- Stories
- Contact
- Donate

The donation form does not collect card details or process payments. Connect a verified payment provider before accepting payments.
